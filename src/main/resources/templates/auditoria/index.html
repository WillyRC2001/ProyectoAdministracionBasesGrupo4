Objetos inválidos o con errores

SQL Server no utiliza el concepto de objeto «inválido» de la misma forma que Oracle. En este módulo se detectan referencias a objetos inexistentes, índices y triggers deshabilitados, además de restricciones no confiables.

Los problemas detectados pueden corregirse desde Mantenimiento .
